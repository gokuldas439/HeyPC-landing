# Jarvis: how it works

An animated walkthrough of [Jarvis](https://github.com/gokuldas439/voice-jarvis), the free open-source voice assistant for Windows. It shows what appears on screen for each command.

It's one static `index.html` with no build step. Link straight to a scene with a hash, for example `#type`, `#open`, `#search` or `#stop`.
