Questions

Is it really free?

Yes. There's no paid plan, no trial and no API key to buy.

Does it need the internet?

Understanding your voice works offline. The natural voices are online and send only the sentence HeyPC is about to say to Microsoft's read-aloud service. You can pick an offline voice in Settings. Web search and ChatGPT or Claude need the internet too.

Why does Windows show a warning when I install it?

The installer isn't code-signed, because signing certificates cost money. Choose More info, then Run anyway. The full source code is on GitHub if you'd like to check it first.

What do I need to run it?

Windows 11 and a microphone. It's about 700 MB because the speech models come included. 8 GB of RAM is recommended.

Which languages does it understand?

English for now.
